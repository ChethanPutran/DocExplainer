"""
User Profile Service Implementation

This module provides comprehensive user profile management for Doc Explainer,
including mastery level tracking, learning preference management, and profile persistence.

COMPONENTS CREATED
==================

1. USER PROFILE MODELS (src/core/user/models/user_profile.py)
   - UserProfile: Main profile data class with all user data
   - ConceptMastery: Tracks mastery and progression for individual concepts  
   - LearningPreferences: Stores user learning preferences
   - MasteryLevel: Enum (Novice, Intermediate, Expert, Mastered)
   - ExplanationDepth: Enum (1-5 scale)
   - LearningPace: Enum (Slow, Normal, Fast)
   - PreferredModality: Enum (Text, Visual, Interactive)
   - QuizFrequency: Enum (Never, Rarely, Sometimes, Often, Always)

2. USER PROFILE SERVICE (src/core/user/services/user_profile_service.py)
   - UserProfileService: Main service class for profile management
   - 31 public methods covering all profile operations
   - Thresholds: DEFAULT_KNOWN_THRESHOLD = 0.7
   - Features:
     * Known/unknown concept classification with quick lookup
     * Dynamic mastery level calculation
     * Learning preference management
     * Profile import/export
     * Caching for performance

3. USER PROFILE REPOSITORY (src/core/user/repository/user_profile_repository.py)
   - BaseUserProfileRepository: Abstract base class
   - UserProfileRepository: File-based implementation
   - Features:
     * CRUD operations (Create, Read, Update, Delete)
     * Profile persistence to JSON
     * Backup management with timestamped backups
     * Export/import with wrapper format
     * Query methods for statistics
     * Profile searches by mastery range and preferences

4. TEST SUITES (src/core/user/tests/)
   - test_user_profile_service.py: 50+ tests for service
   - test_user_profile_repository.py: 33+ tests for repository
   - All tests use pytest fixtures
   - Full coverage of features and edge cases


FEATURE OVERVIEW
================

KNOWN/UNKNOWN CONCEPT MAPPING
- Binary classification based on configurable threshold (default: 0.7)
- Quick membership testing via cached sets
- Dynamic threshold adjustment
- Support for custom thresholds per-classification

Methods:
  classify_concept(concept_name, p_knowledge, threshold=None) -> bool
  is_concept_known(concept_name, threshold=None) -> bool
  get_known_concepts(threshold=None) -> Dict[str, ConceptMastery]
  get_unknown_concepts(threshold=None) -> Dict[str, ConceptMastery]
  get_known_concepts_set(threshold=None) -> Set[str]


MASTERY CATEGORIZATION
- Dynamic level calculation from p_knowledge (probability of knowing)
- Four mastery levels:
  * Novice: p_knowledge < 0.3
  * Intermediate: 0.3 <= p_knowledge < 0.7
  * Expert: 0.7 <= p_knowledge < 0.9
  * Mastered: p_knowledge >= 0.9

Methods:
  calculate_mastery_level(p_knowledge) -> MasteryLevel
  get_concepts_by_mastery(level) -> Dict[str, ConceptMastery]
  get_mastery_distribution() -> Dict[str, int]
  get_average_mastery() -> float
  update_concept_mastery(concept_name, p_knowledge, confidence=0.5)


LEARNING PREFERENCES
- 8 preference categories:
  1. explanation_depth: 1-5 scale (Minimal to Comprehensive)
  2. learning_pace: Slow, Normal, Fast
  3. preferred_modality: Text, Visual, Interactive
  4. quiz_frequency: Never, Rarely, Sometimes, Often, Always
  5. language_preference: ISO 639-1 code (e.g., 'en', 'es')
  6. auto_advanced_quizzes: bool (default: True)
  7. detailed_feedback: bool (default: True)
  8. show_hints: bool (default: True)

Methods:
  get_preferences() -> LearningPreferences
  update_preferences(**kwargs) -> LearningPreferences
  set_explanation_depth(depth)
  set_learning_pace(pace)
  set_preferred_modality(modality)
  set_quiz_frequency(frequency)
  set_language_preference(language)


PROFILE PERSISTENCE
- JSON-based file storage
- Automatic backup creation on updates
- Backup cleanup (keep N most recent)
- Export with metadata wrapper
- Import with validation
- Full serialization/deserialization
- Cache management for performance

Methods:
  save_profile(profile) -> UserProfile
  get_profile(user_id) -> Optional[UserProfile]
  delete_profile(user_id) -> bool
  profile_exists(user_id) -> bool
  list_user_ids() -> List[str]
  export_profile(user_id, export_path) -> bool
  import_profile(import_path) -> Optional[UserProfile]
  reload_profile(user_id) -> Optional[UserProfile]


DATA MODELS
===========

ConceptMastery
-  concept_name: str
-  p_knowledge: float (0-1)
-  mastery_level: MasteryLevel (auto-calculated)
-  first_seen: datetime (auto-set)
-  last_seen: datetime (auto-updated)
-  times_seen: int
-  confidence: float (0-1)

Methods:
-  update_knowledge(p_knowledge): Update and recalculate level
-  is_known(threshold=0.7): Check if known above threshold
-  to_dict()/from_dict(): Serialization

UserProfile
-  user_id: str
-  known_concepts: Dict[str, ConceptMastery]
-  unknown_concepts: Set[str]
-  preferences: LearningPreferences
-  created_at: datetime
-  updated_at: datetime
-  last_active: datetime

Methods:
-  get_known_concepts(threshold): Get concepts known above threshold
-  get_unknown_concepts(threshold): Get concepts unknown below threshold
-  get_concepts_by_mastery(level): Filter by mastery level
-  update_concept_mastery(...): Add or update concept
-  get_mastery_distribution(): Count at each level
-  get_profile_summary(): Generate summary dict
-  to_dict()/from_dict(): Serialization

LearningPreferences
-  All 8 preference fields (see above)
-  created_at, updated_at: datetime tracking
-  to_dict()/from_dict(): Serialization


USAGE EXAMPLES
==============

1. CREATE SERVICE AND CLASSIFY CONCEPTS
   from src.core.user import UserProfileService
   
   service = UserProfileService("user_123")
   is_known = service.classify_concept("Python", 0.85)  # True
   is_known = service.classify_concept("Rust", 0.25)     # False

2. UPDATE MASTERY AND GET STATISTICS
   service.update_concept_mastery("Python", 0.95, confidence=0.9)
   service.update_concept_mastery("Java", 0.65)
   
   stats = service.get_learning_statistics()
   # {
   #   'total_concepts': 2,
   #   'known_concepts': 1,
   #   'average_mastery': 0.8,
   #   'mastered_count': 1,
   #   ...
   # }

3. MANAGE LEARNING PREFERENCES
   prefs = service.get_preferences()
   service.update_preferences(
       explanation_depth=5,
       learning_pace='fast',
       preferred_modality='visual'
   )

4. PERSIST PROFILE
   from src.core.user import UserProfileRepository
   
   repo = UserProfileRepository("data/profiles/")
   profile = service.profile
   saved = repo.save_profile(profile)
   
   # Later: retrieve
   retrieved = repo.get_profile("user_123")

5. EXPORT/IMPORT
   repo.export_profile("user_123", "exports/user_123.json")
   imported = repo.import_profile("exports/user_123.json")

===============

1. CACHING
   - Known concepts cached in memory for fast lookup
   - Cache invalidated on threshold changes
   - Profile cache in repository

2. THRESHOLDS
   - Configurable known/unknown threshold (0-1)
   - Support for custom thresholds per-operation
   - Dynamic recalculation when threshold changes

3. SERIALIZATION
   - All dataclasses support to_dict()/from_dict()
   - Datetime handling with isoformat()
   - Enum value preservation
   - Nested object serialization

4. ERROR HANDLING
   - ValueError for invalid thresholds/confidence
   - File I/O error handling with try/except
   - Validation in from_dict() methods
   - Graceful degradation for corrupt files

5. TIMESTAMPS
   - Automatic tracking of creation/update times
   - ISO 8601 format for serialization
   - Used for backup management and statistics
